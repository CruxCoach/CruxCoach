# Bundled Training Resources

The JSON files in this directory contain CruxCoach's own training reference
data used by the coaching / benchmarking engine. They are **not** derived
from any published training protocol or third-party data source.

| File | Purpose |
|------|---------|
| `benchmarks.json` | Finger-strength, pull-strength, push-up, and core-hold targets keyed by V-grade — internal heuristics used to compare user metrics against a difficulty level |
| `exercises.json`  | Hangboard and conditioning exercise library with DE + EN descriptions |

These files are part of the GPLv3-licensed CruxCoach source code.

If you believe a figure or description was taken from a published source
without proper attribution, please open an issue on the repository — we
will investigate and either cite the source or replace the value.
