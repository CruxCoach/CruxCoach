# Developer Certificate of Origin

Contributions to CruxCoach use the
[Developer Certificate of Origin, version 1.1](https://developercertificate.org/)
as the inbound contribution certification. The canonical text is maintained
at that link.

By contributing, you certify that your contribution satisfies DCO 1.1 and may
be distributed under this repository's GPL-3.0-only license. Add a sign-off to
each commit with:

```bash
git commit -s
```

This produces `Signed-off-by: Name <address>` using your Git identity. The
sign-off is a certification, not a transfer of copyright. Do not submit code,
data, artwork, or other material that you lack the right to contribute.
