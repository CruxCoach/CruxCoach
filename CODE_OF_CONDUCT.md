# Code of Conduct

CruxCoach welcomes contributors and users regardless of experience,
background, identity, ability, or climbing level. Participation in project
spaces requires respectful, constructive behavior.

## Expected behavior

- Discuss ideas and code without personal attacks, harassment, threats, or
  discriminatory language.
- Assume good faith while still giving specific, evidence-based feedback.
- Respect privacy. Do not publish another person's identity, private messages,
  precise private/home location, credentials, or unredacted diagnostic data.
- Stop unwanted contact and de-escalate when asked.
- Keep project spaces focused on building, using, and governing CruxCoach.

These expectations apply in the repository, issue tracker, review threads,
project-linked Nostr conversations, and in-person or online interactions where
someone is representing the project.

## Reporting and enforcement

For non-sensitive conduct concerns, open a public issue or contact the
maintainer through the routes in [MAINTAINERS.md](MAINTAINERS.md). For a report
that contains personal or otherwise sensitive material, use the encrypted
NIP-17 route documented there and include only what is necessary.

The maintainer may edit or remove harmful content, ask a participant to stop,
temporarily restrict participation, or permanently exclude someone from
project-controlled spaces. Decisions should be proportionate, documented to
the affected participants where safe, and avoid unnecessary disclosure of the
reporter or third parties.

This is currently a solo-maintained project and has no independent private
moderation panel. If a concern involves the maintainer, a public Codeberg issue
can provide transparent community review only when doing so would not expose
sensitive information; otherwise, no confidential alternate adjudicator is
currently available.
