# 0.2.3 browser, filters and guided entry

Work starts from release `35920004e` on `feat/0.2.3-browser-ux`.

- One browser header row: board, angle, Bluetooth, filter and overflow. Physical
  angle is edited in a dedicated sheet using the board's supported angle set;
  resetting browse filters leaves that angle intact.
- Filters prioritise grade, sent exclusion/status and sorting. Additional filters
  are expandable with active restrictions summarised; long choices use vertical
  dialogs instead of horizontal scrolling. Existing query semantics are retained.
- Setup retains board/download confirmation and optional imports. BLE connection is
  optional before board picking; first discovery does not prefer the default family.
  Recognised controller names suggest a picker family without excluding alternatives.
  Unknown Aurora names and relays never supply an assumed Kilter suggestion.
- The browser tour has its own persistent state. Setup skip suppresses auto-tour;
  upgrades do not start it. Explicit BLE deferral carries over. Connected users skip
  the connection hint. Angle/filter hints wait for a usable catalogue. Detail hints
  explain projection and logging without writing LEDs or creating log entries.
- Introduction is available again from browser overflow. Existing restore/import,
  download consent, sync preferences and personal data are preserved.

Validation is recorded below after focused tests and device review. No stable
release/main merge is authorised or performed by this work. A CI feature candidate
is needed before the ADB review; local full APK builds are prohibited by AGENTS.md.
