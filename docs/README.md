# CruxCoach documentation

Reader-facing documentation is published in both German and English:

- [`de/`](de/) — German
- [`en/`](en/) — English

Both language versions use the same file name and link to each other at the top. When a reader-facing document is added or materially changed, update both versions in the same commit.

Language-neutral assets such as diagrams and screenshots remain in shared directories. Existing technical specifications and historical implementation records remain at their established paths until they are deliberately localized; moving those normative references merely to imitate a language split would break links and can create ambiguous sources of truth.
