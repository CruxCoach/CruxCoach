# Bundled board-image assets

CruxCoach distributes only the project-created MoonBoard backgrounds and their
coordinate maps from this directory. It does **not** distribute background
images extracted from Kilter Board or other Aurora-family applications.

Kilter, Tension, Grasshopper, Decoy, So iLL, and Touchstone views therefore use
the procedural placements-and-holds renderer. `BoardImageCache` treats an
optional missing background as `null`, so the absence of a third-party image is
a supported rendering mode rather than an error. A downstream fork may provide
its own lawfully redistributable optional backgrounds at the paths generated by
`boardImageCandidatePaths()`.

## MoonBoard assets

| Files | Variant |
|---|---|
| `moonboard_2016.webp` + `moonboard_2016.json` | MoonBoard 2016 |
| `moonboard_2017.webp` + `moonboard_2017.json` | MoonBoard Masters 2017 |
| `moonboard_2019.webp` + `moonboard_2019.json` | MoonBoard Masters 2019 |
| `mini_moonboard_2020.webp` + `mini_moonboard_2020.json` | MoonBoard Mini 2020 |
| `moonboard_2024.webp` + `moonboard_2024.json` | MoonBoard 2024 |

The WebP files are CruxCoach-created renderings, not files extracted from the
official MoonBoard app. The JSON files map each grid position to the measured
hold centre in its matching image. They use normalized `x`/`y` coordinates and
the same 1-based hold-id space as `MoonBoardFrameEncoder`.

The MoonBoard product, physical layout, and name belong to their respective
rights holders. CruxCoach is an independent interoperability project and is not
affiliated with or endorsed by Moon Climbing Ltd.

## Updating

For a new MoonBoard variant:

1. Add a project-created `moonboard_<variant>.webp` and its matching coordinate
   map `moonboard_<variant>.json`.
2. Map the variant to that asset base name in `MoonBoardAsset.assetBaseName()`.
3. Run the MoonBoard asset tests and assemble an APK to verify both files are
   packaged.

Do not add images extracted from a third-party application unless the repository
also carries a redistribution licence that expressly covers those files.
