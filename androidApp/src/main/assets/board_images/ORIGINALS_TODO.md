# Board images — originals replacement manifest

**Status: extracted third-party imagery, pending replacement with CruxCoach-original renders.**

Every image listed here was extracted from the respective vendor's official
app and is **not** licensed to CruxCoach (see `../../../../LEGAL.md` and
`.reuse/dep5`). This file is the work-list for replacing them with
CruxCoach-original renders — the same route already taken for the MoonBoard
set (`moonboard_*.webp` + coordmap `moonboard_*.json`), which are originals
and are **not** listed here.

When an original is produced it must overwrite the **exact same path** at the
**same pixel dimensions** (the hold overlay maps onto these dimensions, so a
size change misaligns the holds). The renderer already supports a per-layout
fallback (`BoardImageCache.getOrDecode`), so files may be swapped one at a time.

Total to replace: **50** images across 6 vendors.
