# Maintainers and Contact

CruxCoach is currently a solo-maintained upstream project. Repository history
is the authoritative record of authorship and review; this file documents
roles and contact routes without assigning a response-time commitment.

For ordinary bugs, feature proposals, and governance questions, use the
[public Codeberg issue tracker](https://codeberg.org/CruxCoach/CruxCoach/issues)
or **Settings → Contact Developer** in the app. Do not include private keys,
access tokens, private climbing notes, precise private/home locations, or
unredacted logs in a public issue.

For vulnerabilities or other sensitive security material, follow
[SECURITY.md](SECURITY.md#reporting-a-vulnerability) and use an encrypted
NIP-17 Nostr DM. The repository has no private issue intake.

Maintainer availability is best-effort. No response, merge, or remediation
deadline is guaranteed. Fork maintainers must replace these routes and the
corresponding build identity fields before distributing their own branded
builds; see [CONTRIBUTING.md](CONTRIBUTING.md#customizing-for-forks).
